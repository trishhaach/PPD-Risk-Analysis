# Postpartum Risk Analysis Backend

Postpartum Risk Analysis is a maternal mental health platform designed to help expecting and new mothers identify the risk of postpartum depression (PPD) and access helpful educational resources and crisis support. The platform allows mothers to complete digital mental health screening and receive personalized guidance based on their responses.

## Introduction

The **backend system** manages the core application logic and data processing for the platform. It handles user authentication, processes postpartum screening inputs, communicates with the prediction module, and provides REST APIs for both web and mobile applications.

The system enables mothers to complete postpartum depression screening, receive risk analysis results, access educational content, and view crisis support resources.

## Features

**User Authentication**  
Secure user registration and login functionality for platform access.

**Postpartum Depression Screening**  
Allows mothers to complete EPDS-based mental health screening to assess emotional well-being.

**Risk Prediction Processing**  
Processes screening responses and interacts with the prediction module to determine postpartum depression risk levels.

**Educational Resources**  
Provides access to articles and guides related to maternal mental health and recovery.

**Crisis Support Resources**  
Displays support resources and guidance based on the user's screening results.

**REST API Services**  
Provides APIs used by web and mobile applications to interact with backend services.

## Technology Stack

**Backend Framework:** FastAPI  
**Database:** PostgreSQL   
**API Testing:** Postman
